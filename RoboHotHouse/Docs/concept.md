# **Концепт-документ: RoboHotHouse – Автономная система умной теплицы**

**Версия:** 0.1 

---

## **1. Видение продукта**
**RoboHotHouse** – автономная система для подогрева воздуха в теплице, обеспечивающая безопасную зимовку комнатных растений на балконе.

> *Ключевой принцип: «Не дать цветку замерзнуть!»*

---

## **2. Ключевые характеристики**

| Параметр               | Значение/Примечание                                                                 |
| ---------------------- | ----------------------------------------------------------------------------------- |
| **Измеряемые величины** | Температура, влажность (ANT20), давление (BMP280), освещенность (опционально)      |
| **Порог обогрева**     | +12°C (активация подогрева)                                                        |
| **Связь**              | Wi-Fi 2.4 ГГц (внешняя антенна - опционально)                                      |
| **Дисплей**            | TFT 1.28" GC9A01 (240x240)                                                         |
| **Управление**         | Тактовая кнопка (переключение экранов/сброс настроек)                              |
| **Питание**            | ~220В → 5V/3.3V для электроники + 12V для обогревателя                             |

---

## **3. Аппаратная часть**

### **3.1. Основные компоненты**
- **Микроконтроллер:** ESP32
- **Датчики:** ANT20 (I2C), BMP280 (I2C), LDR (A0 - опционально)
- **Дисплей:** 1.28" TFT GC9A01 (SPI)
- **Управление:** Тактовая кнопка (GPIO16)
- **Обогреватель:** Коврик 5W или резисторы 10W

### **3.2. Безопасность**
- **Механический выключатель** на корпусе
- **Автомат 2А + УЗО** в цепи 220В
- **Закрытый корпус** перед подключением к сети

---

## **4. Программное обеспечение**

### **4.1. Основные функции**
- Непрерывный мониторинг датчиков (30 сек интервал)
- Автоматический обогрев при T < +12°C
- Кольцевой буфер данных (24+ часов истории)
- REST API (`/status` - текущее состояние)
- Интеграция с RoboHome

### **4.2. Логика управления**
- Включение подогрева при снижении температуры ниже 12*С
- Выключение подогрева при повышении температуры до 14*С

### **5. Особенности конструкции**
**Колпак:** Обрезанная бутылка 5л. 
**Корпус:** Основание PLA, крепления PETG
**Антенна:** Возможность подключения внешней для улучшения сигнала
