# **RoadMap проекта RoboHotHouse**
**Версия:** 0.1

## **Этап 1. НИОКР**
**Срок:** 28-10-2025 - 11-11-2025
**Цель:** Снижение степени новизны проекта и связанных с этим рисков.

**Задачи:**
1. Исследование способов управления переменной нагрузкой
2. Тестирование доступных способов управления переменной нагрузкой
   - Реле механическое
   - Реле твердотельное
3. Аудит компонентов управления нагрузкой ~220В из наличия
4. Исследование нагревательных возможностей коврика
5. Исследование нагревательных возможностей металло-керамических резисторов
6. Прошивка ESP32 в среде VSCode + PIO
7. Подключение датчиков и дисплея к ESP32
8. Схема управления ~220В с раздельным питанием и гальванической развязкой
9. УЗО
   - Принцип действия, характеристики
   - Выбор УЗО
   - Покупка УЗО
   - Установка УЗО

**Результат:**
- [ ] Отчет по способам управления нагрузкой ~220В
- [ ] Лабораторная работа по управлению нагрузкой ~220В и отчет по ней
- [ ] Отчет по аудиту компонентов управления нагрузкой ~220В
- [ ] Лабораторная работа по исследованию нагревательных возможностей коврика и резисторов. Отчет
- Лабораторные работы по подключению модулей к ESP32
  - [ ] Блинкер
  - [ ] AHT20
  - [ ] BMP280
  - [ ] Дисплей
- [ ] Схема управления нагрузкой ~220В с помощью контроллера
- [ ] Лабораторная работа по управлению нагрузкой ~220В с помощью контроллера
- [ ] Выбор УЗО и автомата. Расчет. Отчет
- [v] Установка защиты (УЗО и автомат) на балконе
