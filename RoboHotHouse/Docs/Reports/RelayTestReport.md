# Отчет по лабораторной работе: Тестирование модулей реле для коммутации сети ~220В

## 1. Цель работы
Тестирование двух типов реле (электромеханического и твердотельного) для коммутации нагрузки в сети ~220В с целью выбора оптимального решения для проекта RoboHotHouse.

## 2. Оборудование и компоненты
- Модуль электромеханического реле JQC-3FF-S-Z
- Модуль твердотельного реле G3MB-202P
- Лампа накаливания ~220В
- Патрон Е27
- Провода силовые ~220В
- Вилка сетевая ~220В
- Розетка сетевая ~220В
- Клеммы WAGO
- Блок питания AC-DC 5В
- Макетная плата
- Резисторы 500 Ом (2 шт)
- Тактовая кнопка
- Защитное оборудование: УЗО + автомат 1А тип B

## 3. Схема электрическая
Для обоих типов реле использовалась идентичная схема:
- Цепь управления: 5В → R500Om → кнопка → управляющий вход реле
- Цепь нагрузки: Сеть 220В → реле → лампа
- Гальваническая развязка между цепями управления и нагрузки (конструктивно входит в оба модуля реле)

## 4. Ход работы

### 4.1. Подготовительный этап
- Изготовлены резистивные перемычки 500 Ом
- Обжаты силовые провода (вилка, розетка, патрон, соединительные провода)
- Собрана высоковольтная часть с использованием клемм WAGO

### 4.2. Тестирование электромеханического реле JQC-3FF-S-Z
- Подключена макетка к питанию 5В
- Высоковольтная часть подключена через защиту (УЗО + автомат)
- Высоковольтная часть подключается к реле к Клеммам NO и COM
- При нажатии кнопки наблюдается:
  - Характерный щелчок реле
  - Срабатывание зеленого индикаторного светодиода на модуле реле
  - Индикаторная отвертка паказывает наличие фазы в розетке
  - Мультиметр показывает напряжение 234В в розетке
  - Загорание лампы накаливания (при ее подключении)

### 4.3. Тестирование твердотельного реле G3MB-202P
- Подключена макетка к питанию 5В
- Высоковольтная часть подключена через защиту (УЗО + автомат)
- Высоковольтная часть подключается к реле к клеммам A1 и B1 
- При нажатии кнопки наблюдается:
  - Отсутствие щелчков и иных шумов
  - Срабатывание красного индикаторного светодиода на модуле реле
  - Индикаторная отвертка паказывает наличие фазы в розетке
  - Мультиметр показывает напряжение 230В в розетке
  - Загорание лампы накаливания (при ее подключении)

## 6. Выводы

1. **Оба реле работоспособны** и успешно коммутируют нагрузку 220В
2. **Электромеханическое реле** подходит для проектов с редкими переключениями
3. **Твердотельное реле** предпочтительнее для частых переключений (ПИД-регулятор)
4. **Безопасность** обеспечена применением УЗО и автомата защиты
5. **Для проекта RoboHotHouse** рекомендуется G3MB-202P из-за:
   - Бесшумной работы
   - Высокого ресурса
   - Быстрого срабатывания
