# **Changelog: Дорожная карта (Roadmap) проекта RoboHotHouse**

### [Версия 0.3] — 2026-03-02
**Основание:** Фиксация результатов ретроспективы Этапа 2 (Прототип) и пересмотр дорожной карты в связи с выявлением критических проблем.

**Изменения:**

- **Этап 2 (Прототип):**
  - Статус изменён на «Проблемы с надежностью. Приостановлен для НИОКР2»
  - Уточнены результаты: добавлены пометки о частичной реализации логирования и необходимости уточнения методики испытаний.

- **Структура этапов:**
  - **Добавлен промежуточный Этап 2.5 «НИОКР2»**

- **Этап 2.5 (НИОКР2):**
  - **Новая цель:** Проведение дополнительных исследований для решения критических проблем, выявленных на этапе 2.

- **Этап 3 (Изделие):**
  - Срок начала изменён с «уточнить по результатам Этапа 2» на «уточнить после завершения НИОКР2»

**Технические решения, отражённые в изменениях:**
- Принят адаптивный подход к разработке: при выявлении фундаментальных проблем вводится промежуточный исследовательский этап.
- Повышена приоритетность диагностики и обеспечения надежности перед переходом к финальной сборке.
- Подтверждён фокус на решение конкретных инженерных задач (нагрев, распределение тепла) перед масштабированием.

### [Версия 0.2] — 2025-12-14
**Основание:** Фиксация результатов ретроспективы Этапа 1 (НИОКР) и пересмотр структуры разработки на основе практических выводов.

**Изменения:**

- **Этап 1 (НИОКР):**
  - Все задачи отмечены статусом «✅ Выполнено»
  - Срок выполнения скорректирован с «28-10-2025 – 11-11-2025» на «28-10-2025 – 14-12-2025»
  - Добавлена колонка «Результат» с отметками выполнения для каждой подзадачи
  - Уточнён пункт 7: «Лабораторная работа по управлению нагрузкой ~220В с помощью контроллера (частично: вместо сигнала контроллера использовалась тактовая кнопка)»

- **Структура этапов:**
  - **Этап «Высоковольтная часть» упразднён** как универсальный модуль
  - **Этап «Прототип»** (бывший Этап 3) перенесён на позицию Этапа 2
  - **Этап «Изделие»** (бывший Этап 4) перенесён на позицию Этапа 3
  - **Этап «Поддержка RoboHomeLinq»** сохранил позицию Этапа 4

- **Этап 2 (Прототип):**
  - Срок определён: 15-12-2025 – 28-12-2025
  - Уточнён состав: контроллер на макетке, один нагревательный коврик, один AC-DC 5В
  - Релейный модуль изменён с JQC-3FF-S-Z на **G3MB-202P** (готовый SSR-модуль)
  - Добавлена задача по реализации REST API для выдачи лога в JSON
  - Уточнены критерии испытаний: запись суточного лога температур и состояния нагревателя

- **Этап 3 (Изделие):**
  - Срок оставлен для уточнения по результатам Этапа 2
  - Уточнена конфигурация высоковольтной части:
    - AC-DC 5В × 2 (для контроллера и до 5 модулей HotCell5V)
    - Релейный модуль G3MB-202P для управления ковриком
  - Добавлена задача по испытаниям с записью лога

- **Этап 4 (Поддержка RoboHomeLinq):**
  - Без изменений, срок не определён

**Технические решения, отражённые в изменениях:**
- Отказ от универсального высоковольтного модуля в пользу специализированного решения
- Принят итеративный подход: прототип → изделие → интеграция
- Подтверждён выбор G3MB-202P как основного релейного модуля (готовый SSR с оптической развязкой)
- Фокус на быстрый прототип для валидации концепции нагрева

### [Версия 0.1] — 2025-10-28
**Основание:** Первичная разработка дорожной карты проекта.

**Ключевые элементы:**
- Общая структура из 5 этапов:
  1. НИОКР
  2. Высоковольтная часть
  3. Прототип
  4. Изделие
  5. Поддержка RoboHomeLinq
- Акцент на создании универсального высоковольтного модуля
- Предполагалась последовательная реализация с чёткими сроками для первых двух этапов
- Включены задачи по исследованию реле (механических и твердотельных), нагревательных элементов и системы защиты (УЗО)

---

**Примечание:**  
Изменения в версии 0.2 основаны на результатах ретроспективы Этапа 1 (НИОКР) и практических выводах о неэффективности универсального подхода к высоковольтной части. Документ актуализирован в соответствии с итеративной методологией разработки.
