## ⚡ **СПРАВОЧНИК: ОСНОВНЫЕ ХАРАКТЕРИСТИКИ GPIO ESP32**

### 🔌 **ЭЛЕКТРИЧЕСКИЕ ПАРАМЕТРЫ**
- **Напряжение логических уровней:** 3.3V
- **Максимальный выходной ток на пин:** 40 mA
- **Суммарный ток всех пинов:** 200 mA
- **Входное напряжение:** не более 3.3V

### 🎛️ **ФУНКЦИОНАЛЬНЫЕ ВОЗМОЖНОСТИ**
- **Все GPIO** поддерживают прерывания (interrupts)
- **Все GPIO** (кроме 34-39) имеют встроенные подтяжки: Pull-up/Pull-down
- **ШИМ (PWM)** доступен на всех пинах через LEDC
- **АЦП (ADC):** 12-битный, 0-3.3V, на пинах 2,4,12-15,25-27,32-39
- **ЦАП (DAC):** 8-битный, только GPIO 25,26
- **Touch-сенсоры:** GPIO 2,4,12-15,27,32,33

### ⚠️ **ОГРАНИЧЕНИЯ И ОСОБЕННОСТИ**
- **GPIO 34,35,36,39** - только вход, без подтяжки
- **GPIO 6-11** - заняты под Flash память
- **GPIO 0,2,12,15** - критичны при загрузке
- **GPIO 1,3** - UART для программирования

## 🔑 **РЕКОМЕНДАЦИИ ДЛЯ УПРАВЛЕНИЯ КЛЮЧАМИ (5 ШТУК)**

### 🎯 **ОПТИМАЛЬНЫЕ ПИНЫ ДЛЯ КЛЮЧЕЙ:**
```cpp
#define KEY_1   12   // Стабильный, без ограничений при загрузке
#define KEY_2   13   // Надежный, с ШИМ
#define KEY_3   16   // Удобное расположение на плате  
#define KEY_4   17   // Группируется с GPIO16
#define KEY_5   18   // Стабильный ШИМ, нет ограничений
```

### 🔄 **РЕЗЕРВНЫЕ КЛЮЧИ:**
```cpp
#define KEY_ALT_1   19   // Запасной вариант
#define KEY_ALT_2   23   // Запасной вариант
```

### 💡 **ПРЕИМУЩЕСТВА ВЫБРАННЫХ ПИНОВ:**
1. **GPIO 12, 13** - Не имеют ограничений при загрузке
2. **GPIO 16, 17** - Удобно сгруппированы на плате
3. **GPIO 18** - Стабильная работа ШИМ
4. **Все пины** поддерживают прерывания и ШИМ
5. **Хорошая физическая расположенность** на плате DevKit
