## **Этап 1. НИОКР**
**Срок:** 28-10-2025 - 11-11-2025
**Фактически:** 28-10-2025 - 14-12-2025

**Цель:** Снижение степени новизны проекта и связанных с этим рисков.

**Задачи:**
1. Исследование способов управления переменной нагрузкой
2. Тестирование доступных способов управления переменной нагрузкой
   - Реле механическое
   - Реле твердотельное
3. Аудит компонентов управления нагрузкой ~220В из наличия
4. Исследование нагревательных возможностей коврика
5. Исследование нагревательных возможностей металло-керамических резисторов
6. Прошивка ESP32 в среде VSCode + PIO
7. Подключение датчиков и дисплея к ESP32
8. Схема управления ~220В с раздельным питанием и гальванической развязкой
9. УЗО
   - Принцип действия, характеристики
   - Выбор УЗО
   - Покупка УЗО
   - Установка УЗО

**Результат:**
- [v] Отчет по способам управления нагрузкой ~220В
- [v] Лабораторная работа по управлению нагрузкой ~220В и отчет по ней
- [v] Отчет по аудиту компонентов управления нагрузкой ~220В
- [v] Лабораторная работа по исследованию нагревательных возможностей коврика и резисторов. Отчет
- Лабораторные работы по подключению модулей к ESP32
  - [v] Блинкер
  - [v] AHT20
  - [v] BMP280
  - [v] Дисплей
- [v] Схема управления нагрузкой ~220В с помощью контроллера
- [v] Лабораторная работа по управлению нагрузкой ~220В с помощью контроллера (частично. вместо сигнала контроллера использовалась тактовая кнопка)
- [v] Выбор УЗО и автомата. Расчет. Отчет
- [v] Установка защиты (УЗО и автомат) на балконе

##**Этап 2. Прототип**

**Срок:** 15-12-2025 - 28-12-2025

**Цель:** 
- создание полнофункционального прототипа теплички с ковриком в качестве нагревателя. (без резисторов)
- опытная эксплуатация теплички при ручном контроле температуры воздуха на балконе

**Задачи:**
1. Сборка высоковольтной части (коммутатор (ВАГО), ввод (шнур с вилкой), AC-DC 5В, релейный модуль, розетка для подключения коврика ) 
2. Сборка контроллера на макетке (esp32, aht-20, bmp-280, ds18b20, tft 1.28, кнопка)
3. Выходной каскад управления релейным модулем G3MB-202P.
4. Подключение коврика к розетке, управляемой релейным модулем. 
5. Прошивка, реализующая
    - логику управления нагрузкой
    - вывод показателей на дисплей
    - управление дисплеем кнопкой
	- REST API - выдачу лога в формате json
5. Выбор, реализация и настройка алгоритма поддержания заданной температуры. 
6. Испытания теплички: запись суточного лога внутренней температуры, внешней температуры и состояния коврика (вкл/выкл)

**Результат:**
- [ ] Работающий прототип в сборе
- [ ] Логгирование температур и состояния нагревателя
- [ ] Отчет об испытаниях. Подтверждение способности корректировать нижний порог внутренней температуры на +5С к внешней.
