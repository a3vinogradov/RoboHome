#**RoadMap проекта RoboHotHouse**

##**Этап 1. НИОКР**
**Срок:** Дни 1-7 (28.08 - 03.09)
**Цель:** Снижение степени новизны проекта и  связанных с этим рисков.
**Задачи:**
1. исследование способов управления переменной нагрузкой
2. тестирование доступных способов управления переменной нагрузкой
- реле механическое
- реле твердотельное
3. аудит компонентов управления нагрузкой ~220В из наличия
4. исследование нагревательных возможностей коврика (на сколько градусов удастся поднять температуру под колпаком)
5. исследование нагревательных возможностей металло-керамических резисторов. 
6. прошивка ESP32 в среде VSCode + PIO
7. подключение датчиков и дисплея к ESP32
8. схема управления ~22В с раздельным питанием и гальванической развязкой
9. УЗО. 
- Принцип действия, характеристики
- выбор УЗО
- покупка УЗО 
Результат: 
- подтверждение возможности работы с ESP32
- подтверждение возможности управления переменной нагрузкой ~220В
- подтверждение нагревательных возможностей коврика (+10 градусов под колпаком)

Этап 1. Высоковольтная часть.
1. схема электрическая 
2. определение управляющего интерфейса (с гальванической развязкой)
3. разводка PCB
4. плата (ЛУТ)
5. пайка компонентов 
6. компоновка
7. 3d модель корпуса
8. Печать корпуса
9. Сборка узла высоковольтной части
Результатом должна стать закрытая коробка с
- проводом и вилкой ~220В
- розеткой для включения коврика (не хочу на этом этапе резать провода)
- разъемом JST-npin для выдачи стабилизированных 5В для контроллера и линий управления выключателями (Релейный модуль G3MB-202P предположительно) 

Этап 2. Прототип
1. сборка стенда на макетке (esp32, cnt-20, bmp-280, tft 1.28)
2. прошивка, реализующая
  - логику управления нагрузкой
  - вывод показателей на дисплей
  - управление дисплеем кнопкой
3. выходные каскады управления нагрузкой с транзисторами и оптопарами
4. подключение к высоковольтному узлу и реальное управление нагрузкой 
5. настройка алгоритмов (ПИД-регулятор?) поддержания заданной температуры
Результат: 
- управление нагрузкой по наперед заданному алгоритму

Этап 3. Изделие
1. схема электрическая 
2. разводка PCB
3. изготовление платы (ЛУТ)
4. пайка компонентов (контроллер съемный)
3. Модель корпуса
4. печать корпуса
5. сборка изделия
6. отладка и настройка
Результат: 
- управление нагрузкой по наперед заданному алгоритму
- эстетичное, безопасное устройство.

Этап 4. Поддержка RoboHomeLinq
1. Веб-интерфейс
- стартовая страница с текущими показаниями
- настройки 
- about
2. Страница лога и сам лог
3. Интеграция в RoboHome
- поддержка протокола RoboHomeLinq
- добавление адаптеров для RoboHotHouse в RoboCore
Результат: 
- RoboHotHouse отображается в интерфейсе RoboCore
- RoboHotHouse выполняет команды, поступившие из интерфейса RoboCore
