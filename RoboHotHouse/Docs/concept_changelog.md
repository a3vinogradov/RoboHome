# **Changelog: Концепт-документ проекта RoboHotHouse**

### [Версия 0.1] — 2025-10-28  
**Основание:** Первоначальная разработка концепта проекта.

**Ключевые элементы:**
- Определено видение продукта: автономная система для подогрева воздуха в теплице на балконе
- Сформулирован ключевой принцип: «Не дать цветку замерзнуть!»
- Установлены целевые параметры:
  - Измеряемые величины: температура, влажность, давление, освещённость (опционально)
  - Пороги обогрева: включение при +12°C, выключение при +14°C
  - Связь: Wi-Fi 2.4 ГГц
  - Питание: ~220В → 5V/3.3V для электроники + 12V для обогревателя
- Определена аппаратная часть:
  - Микроконтроллер ESP32
  - Датчики AHT20, BMP280
  - Дисплей TFT 1.28" GC9A01
  - Обогреватель: коврик 5W или резисторы 10W
- Описаны основные функции ПО:
  - Мониторинг датчиков с интервалом 30 сек
  - Автоматический обогрев по заданным порогам
  - Кольцевой буфер данных (24+ часов)
  - REST API `/status`
  - Интеграция с RoboHome
- Указаны особенности конструкции:
  - Колпак из обрезанной бутылки 5л
  - Корпус из PLA/PETG
  - Возможность подключения внешней антенны
- Установлена лицензия MIT
- Указан автор (a3v1) и репозиторий проекта

---

**Примечание:**  
Данный документ описывает первоначальную концепцию системы RoboHotHouse. Все последующие изменения будут фиксироваться в этом changelog с указанием версий, дат и обоснований изменений.
