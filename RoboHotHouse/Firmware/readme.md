## 📁 Список прошивок

### 🔬 HotHouse_RnD
**Комплексное тестирование оборудования**  
Полное тестирование всех устройств системы:
- Дисплея
- Датчиков различных типов
- Реле и исполнительных устройств
- И других компонентов

### 🌡️ Test18b20
**Сканер устройств OneWire**  
Прошивка для поиска и идентификации устройств на шине OneWire (реализована в Arduino IDE)

### 🔍 Test18b20_PIO
**Тест датчиков DS18B20**  
Специализированный тест для датчиков температуры DS18B20.  
*Инструкция по подключению находится в комментариях к коду*

### 🖥️ TestTFT_1_28
**Тест круглого дисплея**  
Проверка работы круглого TFT-дисплея диаметром 1.28 дюйма
*Инструкция по подключению находится в комментариях к коду*

⚠️ **ВАЖНОЕ ПРЕДУПРЕЖДЕНИЕ**  
Перед использованием:
- Найти и отредактировать файл `User_Setup.h`
- Раскомментировать строку `#define GC9A01_DRIVER`
- Если оставить настройки по умолчанию - возможен выход из строя дисплея или стабилизатора AMS1117 на отладочной плате!
 
## 💡 Использование

1. Выберите нужную прошивку в зависимости от тестируемого компонента
2. Следуйте инструкциям в комментариях к коду (если имеются)
3. Для комплексного тестирования используйте `HotHouse_RnD`
