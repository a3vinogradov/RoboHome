# **Roadmap проекта RoboCore – системы автоматизации RoboHome**

---

## **🎯 Первая очередь работ – Создание прототипа приложения**

### **🔹 Этап 1. Каркас UI**  
- Разработка веб-приложения на **C# / ASP.NET Core / PostgreSQL**  
- Создание базового дизайна веб-страниц  
**📌 Результат:**  
✔ Приложение запускается и отображает индексную страницу с минимальным дизайном  

---

### **🔹 Этап 2. Добавление компонента RoboDevice**  
**RoboDevice** – базовый компонент для устройств с минимальной функциональностью:  
- Модель устройства  
- Хранение данных в БД  
- Виджет в UI (статус: **OK / Error**)  

**📌 Результат:**  
✔ В БД вручную добавлены **3 устройства** типа RoboDevice  
✔ В БД вручную добавлена **история состояний**  
✔ В UI отображаются виджеты с актуальным статусом  

---

### **🔹 Этап 3. REST API**  
- Разработка **протокола обмена данными** между IoT-устройством и RoboCore  
- Создание **RoboDeviceEmulator** (эмулятор устройства)  
- Реализация **механизма обмена данными** между RoboCore и эмулятором  

**📌 Результат:**  
✔ RoboDeviceEmulator **запущен и работает стабильно**  
✔ RoboCore **корректно принимает и обрабатывает данные**  
✔ Виджеты содержат **кнопку обновления**, инициирующую запрос к устройству  
✔ Данные **обновляются в БД и UI**  

---

### **🔹 Этап 4. Админка**  
- Добавление страницы **Settings**  
- Функционал:  
  - Регистрация новых устройств  
  - Удаление устройств  
  - Редактирование информации  
  - Настройка **интервалов опроса**  

**📌 Результат:**  
✔ Администратор может **управлять устройствами** через веб-интерфейс  

---
