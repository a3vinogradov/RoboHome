# **Концепт-документ: RoboCore – система автоматизации RoboHome**  

## **1. Общее описание**  
**RoboCore** – это веб-приложение для управления IoT-устройствами в экосистеме **RoboHome**. Оно обеспечивает:  
- **Централизованный контроль** устройств (RoboWind, RoboPlant и других).  
- **Автоматический сбор данных** по расписанию и в реальном времени.  
- **Визуализацию** состояния устройств через интерактивные виджеты.  
- **Управление** устройствами (отправка команд).  
- **Обработку событий**, включая push-уведомления о критических состояниях.  

## **2. Архитектура**  

### **2.1. Компоненты системы**  
| Компонент            | Описание                                                                 |
|----------------------|--------------------------------------------------------------------------|
| **RoboCore Backend** | Серверная часть на C# (ASP.NET Core), обрабатывает логику и API.        |
| **RoboCore UI**      | Веб-интерфейс (Blazor/React) для отображения виджетов и управления.      |
| **RoboHome Devices** | Устройства (RoboWind, RoboPlant), подключенные через API или MQTT.       |
| **RoboCore DB**      | База данных (PostgreSQL/SQL Server) для хранения конфигураций и данных.  |
| **Scheduler**        | Планировщик задач (Hangfire/Quartz) для регулярного опроса устройств.   |
| **Event Hub**        | Сервис обработки событий (SignalR) для мгновенных уведомлений.          |

### **2.2. Взаимодействие компонентов**  
1. **Устройства** передают данные через API.  
2. **Backend** сохраняет данные в **RoboCore DB** и обновляет UI через **SignalR**.  
3. **Пользователь** управляет устройствами через **RoboCore UI**.  
4. **Scheduler** автоматически опрашивает устройства по расписанию.  

## **3. Основные сущности**  

### **3.1. Типы устройств**  
- **RoboWind** (метеостанция)  
- **RoboPlant** (устройство автополива)  
- *Поддержка добавления новых типов*  

### **3.2. Модель данных**  
- **Устройство** (ID, название, тип, статус, конфигурация).  
- **Данные устройства** (метрики, показания, временные отметки).  
- **События** (критические/обычные, время возникновения, тип).  

## **4. Функциональность**  

### **4.1. Управление устройствами**  
- Регистрация новых устройств.  
- Настройка параметров (интервалы опроса, триггеры событий).  
- Группировка устройств по категориям.  

### **4.2. Автоматизация**  
- **Плановый опрос** (раз в N минут).  
- **Push-уведомления** (если устройство инициирует событие).  
- **Командный API** (включение/выключение, изменение режимов).  

### **4.3. Пользовательский интерфейс**  
- **Дашборд** с виджетами устройств.  
- **Динамическое обновление** (графики, статусы в реальном времени).  
- **Детальные страницы** для каждого устройства (история, настройки).  

---  
**RoboCore** – это гибкая и масштабируемая платформа для автоматизации **RoboHome**, обеспечивающая удобное управление устройствами и сбор данных в реальном времени.
