# RoboCore – система автоматизации RoboHome

**RoboCore** – это веб-приложение для централизованного управления IoT-устройствами в экосистеме **RoboHome**. 
Оно предоставляет удобный интерфейс для мониторинга, управления и автоматизации устройств, таких как RoboWind, RoboPlant и других.

## 🚀 Возможности

- **Централизованное управление** устройствами RoboHome.
- **Автоматический сбор данных** по расписанию и в реальном времени.
- **Визуализация** состояния устройств через интерактивные дашборды.
- **Управление устройствами** (отправка команд, изменение режимов).
- **Обработка событий** с push-уведомлениями о критических состояниях.
- **Гибкая настройка** параметров устройств и триггеров событий.

## 🏗️ Архитектура

### Основные компоненты

| Компонент            | Описание                                                                 |
|----------------------|--------------------------------------------------------------------------|
| **RoboCore Backend** | Серверная часть на C# (ASP.NET Core)                                    |
| **RoboCore UI**      | Веб-интерфейс (Blazor/React)                                            |
| **RoboHome Devices** | Устройства, подключенные через API/MQTT                                 |
| **RoboCore DB**      | База данных (PostgreSQL/SQL Server)                                     |
| **Scheduler**        | Планировщик задач (Hangfire/Quartz)                                    |
| **Event Hub**        | Сервис обработки событий (SignalR)                                      |

### Взаимодействие компонентов

1. Устройства передают данные через API.
2. Backend сохраняет данные в БД и обновляет UI через SignalR.
3. Пользователь управляет устройствами через веб-интерфейс.
4. Scheduler автоматически опрашивает устройства по расписанию.

## 📦 Поддерживаемые устройства

- **RoboWind** (метеостанция)
- **RoboPlant** (система автополива)
- *Возможность добавления новых типов устройств*

## 📊 Модель данных

Основные сущности:
- **Устройство** (ID, название, тип, статус, конфигурация)
- **Данные устройства** (метрики, показания, временные отметки)
- **События** (тип, время возникновения, критичность)
