О проекте

RoboCore начался как хобби-проект в 2021 году с простой системы автоматизации полива растений. Сегодня это полноценная экосистема для управления умным домом, полностью созданная с нуля с использованием открытых технологий и DIY-подхода.

Все компоненты системы разрабатываются с акцентом на энергоэффективность, простоту обслуживания и возможность кастомизации под индивидуальные потребности.

Основные компоненты

RoboCore

Центральный хаб управления с веб-интерфейсом

RoboWind

Уличная метеостанция с датчиками температуры, влажности и давления

RoboPlant

Система автоматического полива растений с мониторингом состояния почвы

RoboNet

Сетевой модуль для связи между устройствами

Используемые технологии

Аппаратная часть

ESP32, Raspberry Pi, Arduino, собственные PCB

Программная часть

Python, C++, JavaScript, MQTT, REST API

Интерфейс

HTML5, CSS3, Vue.js, WebSocket
