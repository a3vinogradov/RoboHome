# **Концепт-документ: RoboClime – Автономный модуль мониторинга микроклимата**

**Версия:** 0.3 

---

## **1. Видение продукта**

**RoboClime** – это компактный модуль для точного мониторинга параметров атмосферы (температура, влажность, давление). Устройство является частью экосистемы RoboHome и фокусируется на надежности данных за счет аппаратной изоляции датчиков.

> *Ключевой принцип: «Точные данные здесь и сейчас. Стабильность важнее функций».*

---

## **2. Ключевые характеристики**

| Параметр               | Значение/Примечание                                                                                 |
| ---------------------- | --------------------------------------------------------------------------------------------------- |
| **Измеряемые величины** | Температура, относительная влажность (ANT20), атмосферное давление (BMP280), **освещенность (опционально)**|
| **Связь**              | Wi-Fi 2.4 ГГц (внешняя штыревая антенна - **опционально**)                                          |
| **Интерфейсы**         | USB Type-C (питание 5V)                                                                             |
| **Управление**         | Тактовая кнопка (основной орган) с возможностью параллельного подключения вибродатчика (опционально, для тестирования в реальных условиях). |
| **Плата**              | Односторонняя (ЛУТ)                                                                                 |
| **Корпус**             | 3D-печать, **двойные стенки с воздушным зазором** для термоизоляции датчиков                        |
| **Обновление прошивки**| Внутренний разъем для программатора                                                                 |

---

## **3. Аппаратная часть**

### **3.1. Ядро системы**
*   **Микроконтроллер:** ESP8266-07 flash 1М
*   **Датчики:**
    *   ANT20 (Temperature & Humidity, I2C)
    *   BMP280 (Barometric Pressure, I2C)
	*   Датчик освещенности (опционально, аналоговый вход A0)
*   **Дисплей** 1.28" TFT GC9A01 (240x240)
*   **Орган управления:** Тактовая кнопка (GPIO16). На плате реализована возможность параллельного подключения вибродатчика для полевых испытаний.
*   **Антенная система:** Возможность подключения внешней антенны (опционально)
*   **Резерв:** Выведенная контактная площадка (GPIO12) для будущих расширений (управление подсветкой, тач-скрин и т.д.)

### **3.2. Конструктивные особенности**
*   **Термоизоляция:** Датчики вынесены в изолированный отсек с двойными стенками
*   **Вентиляция:** Отверстия для вентиляции только в зоне датчиков
*   **Доступ:** Лючок для доступа к разъему программатора

---

## **4. Программное обеспечение**

### **4.1. Прошивка**
*   **Режим работы:** Постоянное питание от USB
*   **Управление дисплеем:** Постоянная работа. Яркость фиксированная (аппаратная).
*   **Взаимодействие:** REST API для предоставления данных (`/status`)

### **4.2. Логика работы**
1. Непрерывный опрос датчиков 
2. Хранение истории показаний в кольцевом буфере
3. Предоставление данных по API

---

## **5. Особенности реализации**
*   **Стратегия внедрения:** Функциональность устройства в ограниченном объеме реализуется и тестируется на макетной плате (Стенд 1, NodeMCU) до этапа изготовления конечного изделия. Это гарантирует готовность системы к мониторингу к началу ночных заморозков, даже если сроки изготовления корпуса и платы будут сдвинуты.
*   **Орган управления:** Тактовая кнопка подключена на GPIO16. Возможность подключения вибродатчика реализована аппаратно для тестирования.
*   **Термоизоляция:** Физическое отделение датчиков от источников тепла
*   **Разъем программатора:** 5-пиновый (GPIO0, RST, TX, RX, GND) для легкого обновления
