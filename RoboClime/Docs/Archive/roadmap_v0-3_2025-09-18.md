### **Этап 4: Доработка прошивки (После 37 дней)**
*   **4.1. Страница Index** Вывод текущих показаний температуры и суточных экстремумов.
*   **4.2. Страница About** Вывод информации о проекте.
*   **4.3. Страница Settings** Настройки wifi, периода опроса, времени сброса экстремумов и т.п.
*   **4.4. Страница с логом показаний:** Вывод истории измерений за последние N часов.
*   **4.5. Реализация REST API:** Полноценное API для интеграции с RoboHome (отправка данных, управление).
