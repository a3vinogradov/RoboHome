# **Дорожная карта (Roadmap) проекта RoboClime**
**Версия:** 0.1

**Статус:** Утверждена

**Общий срок:** 35 дней

---

### **Этап 1: НИОКР (Исследования и подготовка)**
**Срок:** Дни 1-7
**Цель:** Подготовить все компоненты и решения для быстрой сборки прототипа.

| Задача                                      | Результат                                                                                             |
| ------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| **1.1. Конструктив разъема программатора**  | Выбран тип разъема (скорее всего, 6-пиновый SH1.0). Спроектирована отладочная плата с кнопками FLASH и RST. |
| **1.2. Изготовление шлейфа программатора**  | Готовый шлейф с ключом/полярностью, исключающей неправильное подключение к целевому устройству.         |
| **1.3. Тест вибродатчика (SW-18020P)**      | Подтверждена чувствительность на падение с высоты 1-2 см. Подобран резистор для нужной чувствительности. |
| **1.4. Тест дисплея 1.28 TFT**              | Вывод пикселя, символа, примитива, картинки |

---

### **Этап 2: Прототип на макетке**
**Срок:** Дни 8-18
**Цель:** Собрать и проверить работоспособность всей схемы и логики.

| Задача                                                                                             | Результат                                                                                             |
| -------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| **2.1. Сборка на макетке**                                                                          | ESP8266, дисплей, датчики (ANT20+BMP280) и вибродатчик работают вместе.                               |
| **2.2. Базовая прошивка (Foundation)**                                                              | Прошивка, которая выводит данные с всех датчиков в Serial Monitor. Проверка работы I2C.              |
| **2.3. Прошивка (Управление подсветкой)**                                                            | Реализовано прерывание по вибродатчику, которое включает подсветку на 10 секунд. Антидребезг реализован. |
| **2.4. Прошивка (Сеть и WEB)**                                                                      | Поднят простейший WEB-сервер. Страница `192.168.x.x/status` возвращает JSON с данными датчиков.        |
| **2.5. Тест термоизоляции**                                                                         | Проведен замер температуры датчика при работе ESP. Подтверждена необходимость двойной стенки.          |

---

### **Этап 3: Изделие (Корпус, плата, сборка)**
**Срок:** Дни 19-35
**Цель:** Создать готовое к использованию устройство.

| Задача                                                                                             | Результат                                                                                             |
| -------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| **3.1. Моделирование корпуса (Fusion 360)**                                                          | Готовая 3D-модель корпуса с двойными стенками, посадочными местами под плату и разъем программатора.  |
| **3.2. Печать и доводка корпуса**                                                                    | Напечатанный и доведенный (подшлифованный) корпус. Проверка совместимости всех компонентов.           |
| **3.3. Схема и разводка платы (ЛУТ)**                                                                | Готовая к переносу на текстолит односторонняя схема. Все компоненты помещаются в корпус.             |
| **3.4. Изготовление и пайка платы**                                                                  | Готовая паяная плата, установленная в корпус.                                                         |
| **3.5. Финальная прошивка ("Продакшн")**                                                             | **Готовое изделие.**                                                                                  |
|                                                                                                    | \- Данные выводятся на дисплей.                                                                       |
|                                                                                                    | \- Работает индексная страница с показаниями.                                                         |
|                                                                                                    | \- Есть страница `/config` с настройками (SSID, пароль, яркость).                                       |
|                                                                                                    | \- Есть страница `/about` с версией прошивки.                                                         |
|                                                                                                    | \- Вибродатчик включает подсветку.                                                                    |
