# **Дорожная карта (Roadmap) проекта RoboClime**
**Версия:** 0.2

**Статус:** Утверждена 

**Общий срок:** 37 дней

---

### **Этап 1: НИОКР (Исследования и подготовка)**
**Срок:** Дни 1-7
**Цель:** Подготовить все компоненты и решения для быстрой сборки прототипа.

| Задача                                      | Результат                                                                                             | Статус |
| ------------------------------------------- | ----------------------------------------------------------------------------------------------------- | -------|
| **1.1. Конструктив разъема программатора**  | Выбран тип разъема (скорее всего, 6-пиновый SH1.0). Спроектирована отладочная плата с кнопками FLASH и RST. | ✅ Выполнено с изменениями|
| **1.2. Изготовление шлейфа программатора**  | Готовый шлейф с ключом/полярностью, исключающей неправильное подключение к целевому устройству.         | ✅ Выполнено без ключа|
| **1.3. Тест вибродатчика (SW-18020P)**      | Подтверждена чувствительность на падение с высоты 1-2 см. Подобран резистор для нужной чувствительности. | ✅ Выполнено | 
| **1.4. Тест дисплея 1.28 TFT**              | Вывод пикселя, символа, примитива, картинки | ✅ Выполнено |

*Сроки сдвинуты на 2 дня.*

### **Этап 2: Прототип на макетке**
**Срок:** Дни 10-19
**Цель:** Собрать и проверить работоспособность всей схемы и логики.

| Задача  | Результат  |  
| ------- | ---------- |
| **2.1. Сборка на макетке**    | ESP8266, дисплей, датчики (ANT20+BMP280).  |
| **2.2. Базовая прошивка (Foundation)**    | Прошивка, которая выводит данные с всех датчиков в Serial Monitor. Проверка работы I2C.  |
| **2.3. Прошивка**  | Вывод на экран текущей температуры, температурных экстремумов за последние сутки |
| **2.4. Прошивка (Сеть и WEB)** | Поднят простейший WEB-сервер. Страница `192.168.x.x/status` возвращает JSON с данными датчиков.  |

| **3.2. Печать и доводка корпуса**                 | Напечатанный и доведенный (подшлифованный) корпус. Проверка совместимости всех компонентов.           |
