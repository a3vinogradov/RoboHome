# RoboHome - Автономная система умного дома
  
![Логотип RoboHome](docs/images/logo.png)

**RoboHome** - это модульная система умного дома с акцентом на автономность работы устройств. Основная философия проекта: "Умный дом должен работать, даже когда интернет недоступен".

## 🌟 Особенности системы

- **Децентрализованная архитектура** - устройства работают автономно
- **Локальное управление** - REST/JSON API для интеграции
- **Модульность** - легкое добавление новых устройств
- **Открытый код** - MIT License

## 🧩 Компоненты системы

| Устройство       | Описание                                  | Статус       |
|------------------|------------------------------------------|-------------|
| RoboCore         | Центральный модуль управления            | В разработке |
| RoboPlant        | Умная система автополива                 | В разработке |
| RoboWind         | Метеостанция с онлайн-мониторингом       | В планах    |
