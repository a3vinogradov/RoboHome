### **Changelog: Концепт-документ RoboHome**

**Версия 0.2** 
* **Дата:** 10-10-2025
* **Основание:** Расширение экосистемы устройствами для комнатного использования.
* **Добавлено**
  * Новый компонент **RoboClime** - комнатная метеостанция
  * Новый компонент **RoboHotHouse** - интеллектуальная теплица
  * Конкретные модели датчиков для всех устройств:
    * CNT-20 (температура/влажность)
    * BMP-280 (давление) 
    * LDR (освещенность)
  * Исполнительные устройства (теплый коврик для RoboHotHouse)
* **Изменено**
  * Обновление версии документа до 0.2
  * Убраны пометки "(в планировании)" для всех компонентов
  * Детализировано аппаратное обеспечение для всех устройств
  * Добавлен автор проекта (a3v)
  * Улучшена структура документа

**Версия 0.1** (Исходная)
* **Дата:** 26-06-2025
* **Основание:** Первичная разработка концепции.

	* Определение видения и философии проекта

		* Локальность вычислений
		* Безопасность операций

	* Описание компонентов экосистемы:

	* Определение технических протоколов (JSON/HTTP)
